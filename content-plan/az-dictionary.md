# A-Z BMX Fitment and Identification Dictionary

This document lists the BMX technical terms, dimensional standards, geometry terms, and part variations that determine whether a used part fits a given bike. Each entry is planned as a standalone reference page on bmxpartsdepot.com, with a slug, a plain definition, and a note on why the fitment matters to a buyer. The Confidence column flags rows that carry a specific number, era boundary, or brand claim that should be checked against a primary source before publishing.

## Notes

### Thin letters

These letters do not have five genuine BMX fitment terms, so they were kept short rather than padded.

- **J**: three entries. J-bend spoke is the only universal one. Jam nut is a general mechanical term that genuinely appears on older BMX hubs, and Junior is a real BMX race frame size class. No fourth term was added.
- **K**: three entries. Knurling, Kevlar bead, and keyed washer are all real, but there is no fourth K term worth a page.
- **Q**: three entries, and only quill stem is a strong one. Quad-butted is a real tubing description but is used loosely by brands, so it is marked verify. Quick release brake cable is a genuine detail on used brake sets.
- **V**: three entries. V-brake is real but uncommon on BMX, so the page should say so plainly rather than pretend it is a BMX standard. Vertical dropout is included as a contrast term to the standard slotted BMX dropout and is marked verify because it is rare on BMX frames.
- **X**: the thinnest letter by far. There is no genuine BMX part or standard starting with X. The three entries are 3X lacing (written with an X in normal shop use), Pro XL frame size, and X-up, which earns its place only because it explains detangler demand. Nothing was invented to fill this letter.
- **Y**: three entries. Yoke is used in two genuinely different BMX contexts (chainstay yoke and straddle cable yoke), so both are listed. Yield strength is a materials term that supports the chromoly versus hi-ten comparison.
- **Z**: three entries, and zinc-plated hardware is the weakest of the three. It is included because plating condition is a real identification cue on used old-school parts, not as filler for a dimension page.

### Confidence flags

Every row carrying a shell diameter, thread spec, axle size, hub width, era boundary, or race size class is marked verify. That includes all four bottom bracket standards, spindle and axle diameters, hub spacing, headset standards, seat post diameter, pedal threading, ISO bead seat diameter, and the old school and mid-school era boundaries. These should be checked against a manufacturer spec sheet or a standards reference before the page goes live, because a wrong number on a fitment page costs returns.
